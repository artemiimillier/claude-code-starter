# Планирование недели

Это операционный план владельца, не замена техническому плану в `plans/`. Общий процесс — по ссылке из корневых инструкций. `.business/execution/` добавляется по потребности, после проверки приватности.

```prompt
Спланируем неделю. Прочитай доступные цели, активные планы, последний checkpoint и бэклог. Не требуй годовую/квартальную анкету, если для решения хватает текущей цели. Уточни лишь недостающие ограничения времени и обязательства.

Предложи реалистичные проверяемые результаты и действия с приоритетами, сроками и владельцами. Согласуй новые обязательства. Сохрани в .business/execution/YYYY-WNN.md: фокус, результаты, действия, зависимости, итог. Дату и ISO-неделю проверь инструментом. Не перезаписывай существующий план; актуализируй по фактам.

Свяжи технические задачи с plans/, не копируй архитектуру или весь план реализации. При закрытии недели отметь фактически выполненное, причины остатка и предложи перенос, не объявляя перенос выполнением.
```

Короткие запросы: «добавь задачу [что/когда]», «что на этой неделе?», «итоги недели», «перенеси [задачу]». Если дата есть — соответствующая неделя; без даты — бэклог. Не удаляй историю результата при переносе.

# Подключить второй мозг к существующему проекту

Сначала установи starter по инструкции в его README (dry-run, затем `--apply` после просмотра). Этот промпт нужен для осмысления проекта, а не для переноса или перезаписи кода.

```prompt
Изучи проект [путь]. Начни с текущей задачи, README, локальных инструкций, архитектуры, активных планов, манифестов, ключевых входных точек и тестов. Если есть checkpoint, сверь его с фактами. Следуй общему процессу по ссылке из CLAUDE.md/AGENTS.md.

Не запускай интервью с нуля. Покажи, что подтверждено источниками, что только предполагается и каких данных не хватает для ближайшего решения. Код платежей не доказывает реальные продажи. Спрашивай только о существенных пробелах, без квоты вопросов.

До записи бизнес-контекста проверь ignore и отсутствие tracking; для tracked .business сначала согласуй безопасную защиту.
До создания файлов найди существующий бизнес-индекс и план (в том числе внутри architecture/). Используй их как источники и продолжай существующий план, не создавай параллельные документы. Новый INDEX или план нужен только при отсутствии подходящего. Не меняй существующие данные вслепую. Отдельные разделы добавляй лишь по необходимости; не создавай полную анкету.

Используй один канонический документ архитектуры. Дополни существующий план или, если его нет, составь полный план ближайшего согласуемого результата с фазами, критериями, тестами, review/judge/fix и лимитами. Предложи изменённый план на независимое ревью и одобрение, не начинай несогласованную реализацию и не трогай production.
```

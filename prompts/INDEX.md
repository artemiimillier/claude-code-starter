# Промпты под конкретную задачу

Не обязательная последовательность настройки. Выбери нужное, подставь свой контекст и передай Claude Code или Codex. Сначала агент использует уже доступные документы, код и checkpoint, а не запускает интервью.

Общий процесс — по ссылке из корневого `CLAUDE.md`/`AGENTS.md` (`docs/workflow.md` в клоне, `.starter/workflow.md` после установки). Промпты не заменяют эти правила и не выдают дополнительных полномочий.

| Подключить правила, сохранив свои | [CLAUDE.md и AGENTS.md](setup/05-claude-md-generation.md) |

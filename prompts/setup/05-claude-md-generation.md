# Подключить общие правила Claude Code и Codex

Предпочтительный путь — установщик из README starter: сначала dry-run, затем применение после просмотра. Он сам добавляет управляемые ссылки, не заменяя существующие инструкции. Шаблоны `.tmpl` — образцы только для новых файлов.

```prompt
Проверь корневые CLAUDE.md и AGENTS.md и доступный общий workflow. В клоне он лежит в docs/workflow.md, в установленном проекте — .starter/workflow.md.

Сохрани локальные правила и пользовательские изменения. Не генерируй замену существующему файлу из шаблона. Если общего процесса нет, предложи установку starter; не добавляй неработающую ссылку. Для нового файла используй подходящий образец templates/CLAUDE.md.tmpl или templates/AGENTS.md.tmpl, выбрав верный путь к workflow.

Оставь маршрутизатор коротким: ссылка на единый процесс и необходимые локальные договорённости. Стек возьми из фактов проекта, язык — из текущего общения. Не загружай весь бизнес-мозг и не запускай интервью ради заполнения плейсхолдеров. Не копируй архитектуру и правила процесса в оба файла. Противоречия согласуй, а не скрывай.

Проверь ссылки и покажи diff. Не устанавливай hooks/settings, не меняй permissions и не делай commit/push автоматически.
```

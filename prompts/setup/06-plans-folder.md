# Подготовить plans/ без перезаписи истории

Когда: нужны планы, но папка или её шаблоны отсутствуют. Установщик starter добавляет недостающие файлы консервативно; существующие пропускает.

```prompt
Проверь plans/ и местные правила. Если README.md или TEMPLATE.md отсутствуют, создай недостающие по образцам starter. Существующие файлы, рабочие планы и историю не перезаписывай; предложи точечное согласованное дополнение при необходимости.

План должен описывать весь согласованный результат: цель, контекст, ссылку на одну архитектуру, все фазы, критерии и тесты, независимое ревью, решения судьи, исправления, лимиты и полномочия. Добавь одобрение владельца, checkpoint для продолжения и честный итог. Один план не обязан ограничиваться одной функцией.

Правила процесса бери из workflow по ссылке корневых инструкций, не создавай вторую методологию. Одобрение позволяет пройти все фазы без повторного разрешения на каждую, но не даёт production-доступ. Покажи созданные/пропущенные файлы и проверь ссылки; commit не делай.
```

# HELLO: необязательная проверка файловой дисциплины

Микрозадача показывает, умеет ли агент создать файл, план и checkpoint. **Она не проверяет безопасность, приложение, независимое ревью или весь автономный цикл.** Для реального проекта нужны его тесты, приёмка и review-gates из общего workflow.

```prompt
Проведём учебную проверку файловой дисциплины. Прочитай общий workflow по ссылке из CLAUDE.md/AGENTS.md. Не проводи интервью и не запрашивай приватные данные.

Создай краткий учебный план в plans/ с целью: HELLO.md содержит строку «Привет от проекта». Существующие файлы не перезаписывай; если имя занято, согласуй другое. Эта просьба разрешает только учебные файлы, не production-действия.

Создай HELLO.md, прочитай результат, сравни с критерием. Запиши проверку, checkpoint и итог плана. Отдельно отметь, что независимое ревью и тесты приложения этим упражнением не подтверждены. При полезном наблюдении добавь короткую ретроспективу. Покажи созданные файлы, без commit/push.
```

После проверки учебные файлы можно удалить по отдельной просьбе владельца. Не удаляй автоматически и не объявляй всю среду готовой по наличию HELLO.md.

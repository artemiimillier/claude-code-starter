# templates/ — образцы, не замена локальных правил

`CLAUDE.md.tmpl` и `AGENTS.md.tmpl` — универсальные короткие маршрутизаторы к единому workflow, без плейсхолдеров и обязательной генерации. Используй существующие источники проекта, не проводи анкету ради шаблона.

Ссылка `.starter/workflow.md` рассчитана на корень установленного проекта. В клоне starter корневые инструкции ссылаются на `docs/workflow.md`. Перед использованием образца проверь путь.

Установщик сам добавляет управляемые ссылки в выбранные корневые инструкции, сохраняя их содержимое. Не заменяй существующие `CLAUDE.md`/`AGENTS.md` этими образцами. Существующие шаблоны установщик консервативно пропускает; обновления сравниваются вручную.

`claude-settings.json.example` — справочный образец, не гарантированно совместимый рабочий конфиг. Перед ручным использованием проверь текущую документацию своего агента и ОС. Установщик не активирует settings/hooks, не меняет permissions и не делает git commit/push. Фильтры команд не являются полноценной границей безопасности.
